# Nestfolio binding

This Skill is project-specific. It does not redefine Continuity lifecycle semantics.

- Backlog authority: `docs/backlog/<id>.md`
- Continuity Work mirror and Run references: `continuity/artifacts/`
- Active operational authority: `.continuity/`
- Allowed VS-001 writes are declared in `continuity/bindings/nestfolio/work-items/continuity-vs001-resumable-agent-work-session.json`
- Completion writes `status: shipped` only with the expected source SHA and criterion-linked Evidence.
- `docs/BACKLOG.md` is regenerated by the existing backlog lint procedure.
- No external system is mutated.
