# Continuity Level 1 — Nestfolio backlog-next

This boundary exposes exactly one project-specific Procedure, `nestfolio.backlog-next`, while the existing `.claude/skills/backlog-next/**` files remain the behavior authority.

Commands:

```bash
npm run continuity:doctor
npm run continuity:inspect
npm run continuity:verify
npm run continuity:invoke -- -- --auto
npm run continuity:disable
npm run continuity:activate
```

`continuity:invoke` verifies repository identity, all prerequisites, unique Procedure/asset identity, and every locked SHA-256 before returning the Claude Code `/backlog-next` delegation and structured provenance. It does not execute or reimplement backlog-next semantics.

Only Level 1 is active. Work, Scope, Context Packs, Runs, Checkpoints, Handoffs, Assurance, completion authority, Decisions, Observations, Lessons, and learning promotion are explicitly absent.
