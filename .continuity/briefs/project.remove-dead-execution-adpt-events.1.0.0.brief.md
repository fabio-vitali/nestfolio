called `ExecutionAdptEventTypes` — fourteen event names — that nothing in this
repository emits, consumes, or reads. It is copy-paste residue from another
service. Delete it, in **exactly these two paths and nowhere else**:

- `services/execution/broker-sim-adpt/src/domain/events.ts` — delete the whole
  `export const ExecutionAdptEventTypes = { … } as const;` declaration. Leave
  the `import { eventName } from '@nestfolio/event-types';` line alone: the
  block below it still uses `eventName`.
- `services/execution/broker-sim-adpt/src/domain/index.ts` — the barrel's first
  line re-exports both constants from `./events`. Remove `ExecutionAdptEventTypes`
  from that export list and keep `BrokerSimEventTypes` exactly as it is. Do not
  delete the line; it still exports the constant beside it.

**Two paths, not one.** The backlog note this ask comes from names `events.ts`
alone. The barrel is the second path, and deleting the block without it would
leave the barrel exporting a name that no longer exists.

Keep everything else in both files byte-identical: the same order, the same
formatting, the same blank lines, and no reflowing of untouched code. This is a
deletion, not a tidy-up.

**Change nothing else.** In particular:

- **no file under `.continuity/`.** That is the record of this work, not part of

- no other source file, no lockfile, no `package.json`, and no new file.

When the two files are done, stop. The declared level-1 suite must report its

were already failing before you started, about different changes on open pull
